Optional music for Just a Moment!
Put up to three looping MP3 files here to replace the built-in tune:
  build.mp3  - calm, between shifts
  open.mp3   - main tune while the doors are open (needed for the others to be used)
  tense.mp3  - busy moments: long queues, fires, emergencies
Missing build/tense files fall back to open.mp3. With no open.mp3 the game plays its own built-in music.
Raise GAME_VER in the game code after adding files, so players' browsers pick them up.
