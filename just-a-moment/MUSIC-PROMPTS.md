# Just a Moment! — music prompts (Suno, Udio or any AI music tool)

The game plays its own built-in music until you add recorded tracks. Make up to three tracks. Only **open.mp3** is required; the other two fall back to it.

| File | When it plays | Feel |
|---|---|---|
| `open.mp3` | Doors open, normal day | Cheerful, busy, light satire |
| `build.mp3` | Between shifts, building | Calm, "lift music" |
| `tense.mp3` | Long queues, fire, emergency | Same tune, faster and more frantic |

## Tips before you start
- **Instrumental only:** tick "Instrumental" in Suno, or put "no vocals" in the style box. Lyrics would clash with the speech bubbles and the PA.
- **Make them loop:** ask for a track with no intro or ending, then trim it in the tool if you can. About 1–2 minutes each is plenty.
- **Use the same key and tempo family:** generate `open` first. Then, for the other two, use "Extend" or "Cover" from that track (or paste its style), so all three sound like one song in different moods. The game switches between them smoothly.
- **Download as MP3,** rename to the file names above, and send them to me. I'll put them in `assets/music` and check they loop.

## Short jingles (optional)
The game already plays built-in jingles for VIPs, fires, goals and the Ministry Awards. If you'd like recorded ones too, ask for 2–4 second clips with these styles and send them to me:
- **VIP arrives:** `short 3 second fanfare, pompous brass, snare roll, comedic, instrumental`
- **Fire:** `short 3 second comedic alarm, wobbly brass and bell, instrumental`
- **Ministry Awards:** `short 5 second grand ceremonial fanfare, trumpets and timpani, slightly over the top, instrumental`

## Check before sending
- No singing or spoken words.
- It loops without an obvious jump (play the end into the start).
- Not too loud or bass-heavy: it sits under the sound effects.
